公式資料を読んだ後、自分のコードのどこを確かめるか。その最初の担当箇所と、見落としやすい6つの合成例を、小さなローカルパックで確認できます。

架空例から始める

無料ZIPを取得（約11KB）

Python 3.9以上。標準ライブラリのみ。ZIPを展開し、そのフォルダで実行します。

python3 scan_order_api.py examples/legacy.graphql --json
python3 test_scanner.py
python3 verify_fixtures.py

次に、自分が読む権限を持つソースの狭い範囲を指定します。APIトークンや顧客CSVは不要。スキャナーはソースを変更・送信しません。テストはパック内に結果JSONを作ります。

検出結果を次の仕事へつなぐ

  1. 候補のファイル・行番号を読み、コメントや未使用コードを除きます。単なる文字候補で、GraphQL解析器ではありません。
  2. 数量、複数商品、部分取消、分割発送、旧messagesのnull、Webhook再送から、自分の処理に関係する合成例を選びます。
  3. 現行仕様と権限あるSandboxで、実payload・ページング・保存・状態遷移を担当者が検収してから切替を決めます。

終了コード0や全テスト合格は、実API互換性・検査範囲の完全性・移行完了を証明しません。UTF-8で読めないファイル、サイズ上限、対象なしは不完全として区別します。合成例は実APIレスポンスではありません。
