Watch the state at each step

A cancellation request reserves units but does not subtract remaining quantity. Completion transfers requested units to canceled. Uncanceled units may still ship after a partial cancellation. Same-key identical resends have no second effect; conflicting payloads stop.

Every snapshot conserves purchased = remaining + sent + canceled. A multi-variant failed event leaves the entire prior state intact. Exit 0 means accepted synthetic contract, 2 means stopped, 3 means invalid input/output; all leave real compatibility unconfirmed.

Declared arrival order, at most 1 MiB / 500 events / 100 orders / 1000 total variants. Aliases and synthetic quantities only. It does not reconstruct actual timestamps or implement a real adapter.
