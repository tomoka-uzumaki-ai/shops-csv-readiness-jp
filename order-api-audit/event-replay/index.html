途中の状態も見落とさない

取消依頼中は数量を予約するだけで、残数を減らしません。完了時に取消数へ移します。部分取消後も残りは発送可能。同じキー・同じpayloadの再送は二重適用せず、同じキーの別payloadは停止します。

各snapshotで購入＝残＋発送＋取消を保存します。複数商品イベントが失敗したら、そのイベント全体を適用しません。終了0は合成契約受理、2は途中停止、3は入力/出力不備。どの結果も実互換性は未確認です。
